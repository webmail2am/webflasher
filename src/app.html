AddressPartFile
Drop .bin / .hex files here — addresses are guessed from the file name (bootloader, partitions, boot_app0, littlefs/spiffs, merged…). Check them before flashing.

Filesystem image = littlefs.bin / spiffs.bin / fatfs.bin from PlatformIO “Build Filesystem Image” or mklittlefs. Its address must match your partition table — use “Read partition table from board” below to get it.

Flash options

Erase

Start and size must be multiples of 0x1000. Example: NVS (saved Wi-Fi etc.) in the default Arduino table is 0x9000 / 0x5000. Tip: the partition table below has an “Erase” button per partition.

Partition table, read & backup

A full-chip backup can be written back later as a “Merged .bin @ 0x0”. 4 MB takes about 1–2 minutes at 921600 baud.

EEPROM writes need bootloader support (Mega 2560, Leonardo and Optiboot 8+ yes; the stock Uno bootloader no). If verify fails, use “Clear EEPROM (helper program)” or an ISP programmer.

Erase

The bootloader itself can’t be erased over USB, only the program area. The helper program replaces your sketch with a tiny routine that sets every EEPROM byte to 0xFF and turns the on-board LED on when done — upload your sketch again afterwards. Fuses and burning a bootloader need an ISP programmer (USBasp / Arduino as ISP).
